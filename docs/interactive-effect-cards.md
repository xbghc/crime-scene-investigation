# 交互效果牌：E01 / E03 / E05 / E08

本轮基于草稿 PR #4（8538f11），保留 PR #3 的多人房间、停电刷新和推进门禁修复。

## 玩法与边界

- E01 暗杀：目击者选择存活的非目击者玩家，公开死亡与失去破案权的结果，不公开角色。
- E03 排除嫌疑：目击者选择非目击者、非凶手玩家，所有玩家看到明确的排除结果。
- E05 证据遗失：目击者选择一张已有选项物的场景板移除选项物，再进行通常的推进换板。死亡原因不能被替换，但其选项物可以按照牌面被移除。
- E08 信息泄露：目击者选择当前答案中的手段或线索牌，也可以明确放弃；公开结果包含所指牌的名称和类别。帮凶更换线索后，选项使用最新答案。

E01/E03/E05 必须执行后才能换板和结束推进；没有合法目标时由服务端说明无可执行目标并完成该效果。E08 需要执行或明确放弃后才能结束推进。关闭效果牌介绍、取消尚未提交的选择、刷新页面均不会执行或消耗效果。

服务端提供目击者私有的合法选项与一次性权限。无效请求可以重试；错误角色、伪造效果牌、重复成功请求以及过期请求被拒绝。成功后的公开结果和私有消费状态会随重连快照恢复。场景板普通选项物摆放不能在推进阶段绕过 E05；按照推进规则，随后正常换板会重置新板选项物，因此也允许替换刚被移除选项物的旧板。

## 未扩展内容

E04 / E06 / E10 仍未实现完整交互。这三张牌不在本轮测试覆盖声明内。尤其 E04 的额外第七张板涉及当前 1–6 选项物编号约束，需统一规则后再扩展，不临时创造编号规则。自动效果 E02 / E07 / E09 保留既有机制。

## 验证设计

新增浏览器组通过四个或六个独立 Chromium 会话操作真实中文 UI，覆盖：

1. E01 的合法选择、取消、刷新恢复、公开死亡及破案权限同步。
2. E03 的合法人选限制与公开结果刷新恢复。
3. E05 移除死亡原因选项物、正常换板、跨阶段保持移除结果。
4. E08 公开手段牌名称及刷新、讨论阶段保留结果。
5. E08 明确放弃，不泄露答案且不能重新执行。
6. 六人局帮凶更换线索后，E08 只允许最新答案，并完成两张换板。

所有常规游戏变更由 UI 发起，Pinia 读取仅用于断言。测试入口 `server/e2e/effects-server.ts` 必须在 `NODE_ENV=test` 下使用显式测试凭据，且只监听 loopback；仅根据测试房主昵称前缀选择本次效果牌，不固定角色、手牌、玩家动作、阶段、得分或胜负，没有控制路由。生产入口不导入该入口。

运行新增组：`node node_modules/playwright/cli.js test --config=playwright.effects.config.mjs`。
GitHub Actions 同时运行既有 classic / multiplayer / edges 三组和新增 effects 组；不跳过失败、不配置重试，产物保留七天。每个新增场景保存目击者私有选择面板和侦探公开结果截图，便于视觉核验。最终提交、实际测试数量和 CI 证据以本轮 PR 验证记录为准。
