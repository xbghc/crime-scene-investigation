# 犯罪现场 UI 设计适配

## 参考与范围

本次以 [xbghc/design-system](https://github.com/xbghc/design-system/tree/1301022944d227c3a33d8100c26cc099c38d176c) 的 README、tokens.json 与 Button、Input、Card、Badge、Dialog 说明为依据。令牌和非 React 组件样式快照放在 `client/src/assets/design-system/`，固定到该提交；只进行了格式化，项目适配写在 `main.css`，不直接修改上游令牌含义。

用户明确要求保留游戏特色颜色，因此本项目有以下有意的适配：

- 保留深海军蓝背景、绯红主操作、琥珀调查标记，以及目击者蓝、凶手红、帮凶橙、侦探绿。颜色表达角色、牌种和游戏状态，不把游戏改成纯黑白工具界面。
- 使用 Geist / Geist Mono；中文沿用系统字体。字体失败时仍有系统回退。Lucide 使用当前官方 Vue 包 `@lucide/vue`，图标在构建中打包，不再依赖远程图标字体。
- 采用 4px 间距、8/10/14px 圆角、细边框、轻阴影；14px 界面、12px 辅助文字，减少过小标签与装饰发光。
- 操作目标至少 44px 高，适当大于上游 36px 的桌面按钮标准，以适应手机多人游戏。最窄屏幕的六位密码输入会在保持完整显示的前提下缩窄。
- `--ring` 使用可辨识的琥珀色 3px 键盘焦点，不依赖上游低对比度灰环；错误文字用对比度更高的 `--destructive` 并附文字/图标。

## 改动

- 密码与大厅：聚焦的入口面板、明确标签/说明/错误状态、创建/加入分段选项、清晰的房间码、列表式玩家、主次操作。
- 游戏：统一 HUD 与内容宽度、响应式场景板和玩家卡牌布局、卡牌名称与状态更易读、效果牌私有选择/公开结果更清楚。
- 公用组件：按钮加载语义、可关闭的提示、对话框命名/焦点循环/Escape/焦点返回，原有游戏状态机与权限判断保持不变。
- 图标：统一为本地构建的 Lucide，保留现有 phase/icon 名称映射。
- 图片失败状态：截图复核确认原仓库部分 PNG 无法解码，场景板与卡牌缩略图统一提供 Lucide 占位。可见牌名、类别、选项和交互仍保留；不伪造新牌面、不修改原图片文件。
- 可访问性：可交互卡牌/角色翻面/板选择支持键盘，按钮有明确名称，页面不再禁止缩放，尊重减少动态效果设置。

## 验证方式

原有 classic / multiplayer / edges / effects 共 22 个真实 Chromium 场景继续执行，无跳过或降低原断言。新增 ui 套件检查入口、错误恢复、创建/加入房间、修改昵称取消、四人讨论/卡牌/破案取消与重新打开；覆盖 390px 手机、1440px 桌面、320px 窄屏及 CSS 200% 缩放压力检查。CSS 缩放不代表操作系统或浏览器原生缩放。

PR 工作流另在基线提交运行截图采集，记录基线与证据脚本提交。基线仅省略新增外观断言，正常 ui 套件必须执行；基线效果截图聚焦 E01/E08，当前效果套件仍全量执行。报告与截图作为 CI artifacts 保留 7 天，无发布或部署步骤。

最终测试统计、提交与截图复核结论记录在草稿 PR 中。
