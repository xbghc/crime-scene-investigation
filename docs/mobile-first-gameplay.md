# 手机优先对局适配

本轮接在设计系统 PR #6 的 `0e0e618` 后，继续保留深色、绯红/琥珀和角色语义配色。只改展示与操作，不改服务器、游戏规则、效果实现或角色可见范围；E04/E06/E10 不在本轮实现范围。

## 对局中的改进

- 玩家卡牌可轻点放大，清晰显示玩家、牌种、牌名，并可上一张/下一张连续查看；关闭返回原卡牌焦点。效果更换牌组时自动关闭旧详情，避免读到过时内容。
- 讨论页增加玩家快速定位，十人局无需逐个翻找；保留全员卡牌列表。牌名提升至 14px，破案选牌在手机上为 16px。
- 作案阶段底部常显已选手段与线索，向下查看其他牌时仍能确认当前组合。
- 目击者窄屏布置将排序操作移到场景板上方，避免侧栏挤压三个选项列；破案嫌疑人手机两列，长昵称完整换行。
- 底部操作栏预留与安全区匹配的内容空间；横屏短高度取消大头部吸顶。主内容、底栏和弹窗均照顾左右安全区。
- 对话框依据 VisualViewport 的大小和偏移更新，内容区内部滚动，标题/关闭/底部操作保持可达；键盘缩高后只滚动当前最上层弹窗，使焦点字段进入可视区域。
- 手机输入至少 16px，允许用户缩放；Chrome 支持时请求键盘调整内容视口，同时保留 VisualViewport 回退。

## 验证范围与边界

原有 25 条 Chromium 浏览器场景保留。新增手机套件覆盖触控/手机仿真、320/360/390/430 宽度、横屏与缩高、多人实际 Socket.IO 对局、私有身份、效果选择、破案、结算、重开及重连，另有 WebKit 手机检查。精确执行数和最后提交的 CI 结果以草稿 PR 的终态报告为准。

视口缩高和手动设置 CSS 安全区变量只是模拟检查，不等同于实体 Android/iPhone、原生软键盘、刘海/系统浏览器工具栏的实机验证。

本次云执行环境的依赖年龄策略拒绝安装既有锁文件中的 `@lucide/vue@1.55.0`。没有放宽或绕过策略；本地仅用先前已安装工具做静态编译/格式检查，完整运行测试、类型检查、构建和浏览器验证交由仓库正常 GitHub-hosted CI 环境。没有合并或部署步骤。
